## Énoncé
PhotoSnap: Une balle apparaît à l'écran ainsi qu'une sortie, le joueur prend une photo qui servira de niveau. La balle pourra se déplacer uniquement dans les quatres directions, et ne changera de direction qu'en rencontrant un obstacle.
